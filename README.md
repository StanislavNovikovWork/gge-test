# Таблица данных с виртуализацией

Приложение загружает список фотографий с [JSONPlaceholder](https://jsonplaceholder.typicode.com/guide/), показывает прогресс загрузки в процентах, позволяет отменить загрузку и отображает данные в виртуализированной таблице с поиском и подсветкой совпадений.

## Возможности

- Постраничная загрузка (5000 записей, 250 на страницу) с искусственной паузой между страницами, чтобы прогресс был виден (около 8 секунд).
- Прогресс в процентах и кнопка «Отменить»; уже загруженные строки остаются в таблице.
- Строки появляются в таблице по мере загрузки.
- Таблица с виртуализацией на TanStack Table и TanStack Virtual.
- Поиск без кнопки: запускается через 300 мс после окончания ввода, совпадения подсвечиваются.
- Кнопка «Очистить» очищает таблицу.

## Стек

Vite, React 19, TypeScript, TanStack Table v8, TanStack Virtual, CSS Modules.

## Запуск в Docker

Нужны Docker и Docker Compose.

```bash
docker compose up --build
```

Приложение будет доступно на http://localhost:5173. Исходники монтируются в контейнер, изменения подхватываются без перезапуска (hot reload).

Проверка работоспособности:

```bash
docker compose ps
```

Статус сервиса `app` должен стать `healthy` (healthcheck опрашивает dev-сервер каждые 10 секунд). После этого откройте страницу и нажмите «Загрузить».

Остановка:

```bash
docker compose down
```

## Запуск без Docker

Нужен Node.js 24.

```bash
npm install
npm run dev
```
